# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| main | latest |
| older tags | best-effort (backport security fixes as needed) |

## Reporting a Vulnerability

**Do not open a public issue for a security vulnerability.**

Use GitHub's **Private Vulnerability Reporting** to reach the maintainer:

1. Go to the **Security** tab in this repository.
2. Click **"Report a vulnerability."**
3. Provide a clear description, reproduction steps, and impact assessment.

You'll receive an acknowledgment within 72 hours. If you don't hear back, follow up via the contact info on the maintainer's profile.

## Disclosure Process
- We'll triage the report, confirm the issue, and work on a fix.
- We'll ask for a coordinated disclosure embargo (60-120 days typical).
- We'll credit the reporter in the security advisory and release notes unless you prefer to stay anonymous.

## Safe Harbor
We will not pursue legal action against researchers who follow this process and act in good faith.
